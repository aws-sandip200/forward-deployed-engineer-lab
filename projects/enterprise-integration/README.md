# Project 3 — Enterprise Integration Patterns

Practice connecting services reliably and securely.

## Scenarios
- REST client with timeouts and bounded retries.
- OAuth2 client credentials or workload identity.
- Pagination, rate limiting, and correlation IDs.
- Idempotent handling of repeated requests.
- Resilient error mapping and dead-letter/replay design where appropriate.
- Contract tests against mock upstream services.

## Deliverables
For each integration, include the API contract, sequence diagram, configuration guide, failure-mode table, tests, and operational runbook. Never store credentials in source control.
