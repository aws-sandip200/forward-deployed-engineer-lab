# Forward Deployed Engineer Lab

Hands-on learning and project workspace for Forward Deployed Engineering.

## Focus areas
- Enterprise AI application patterns
- Retrieval-augmented generation (RAG)
- AI agents and tool orchestration
- Enterprise integrations and APIs
- Java, Spring Boot, Angular, Python
- Azure, Docker, Kubernetes, CI/CD
- Observability, security, evaluation, and production readiness

## Suggested structure
```text
docs/             Architecture notes and learning roadmap
projects/         End-to-end applied AI projects
backend/          API and service implementations
frontend/         Web application experiments
deployment/       Docker, Kubernetes, and cloud deployment
tests/            Automated and integration tests
```

Projects will be added as their scope is defined. Keep API keys and other secrets in environment variables or a secret manager, never in source control.
